 TIER SET BONUSES FOR ELEMENTAL SHAMAN
Tier set bonuses are usually standardized to a 2-set and 4-set bonus for each tier set, meaning that one bonus is activated when two pieces of the armor set are worn, while another is activated once four pieces are worn.

For more information on Midnight Season 1 gear and tier set bonuses, check out the Elemental Shaman gear page!

Midnight Season 1 Tier Set Bonuses for Elemental Shaman
The Midnight Season 1 Tier Set amplifies the strength of our short cooldown  Stormkeeper even further. Amping up the number of stacks gained from 2 to 3, increasing the effect e.g. from a 150% buff to  Lightning Bolt to a 215% buff and also giving some additional Haste whenever we use it makes it one of the stronger sub 1-minute cooldowns in the game.
While it doesn't directly change the chosen talents, it is just doubling down on them. Stormbringer would be the choice either way, but with the tier set there really is no contest.
Mantle of the Primal Core
 Shaman Elemental 12.0 Class Set 2pc - Casting  Stormkeeper grants 15% haste for 10 sec.
 Shaman Elemental 12.0 Class Set 4pc -  Stormkeeper grants 1 additional stack and increases the damage of  Lightning Bolt and  Chain Lightning by 25%.

 HOW TO ACQUIRE YOUR ELEMENTAL SHAMAN TIER SET BONUS IN MIDNIGHT SEASON 1
Tier sets can be acquired in three distinct ways:
Raiding: Dropped by specific bosses in Midnight Season 1 Raids.
Great Vault: Obtained by all activities that give Great Vault rewards, including raiding, Mythic+ dungeons, and open world content.
Matrix Catalyst: Creating tier armor from non-set pieces of the same item level using the Matrix Catalyst crafting system.
In Midnight Season 1, the Matrix Catalyst is unlocked for everyone from the start of the season and generates one charge every two weeks.
