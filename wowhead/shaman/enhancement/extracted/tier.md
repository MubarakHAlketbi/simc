Midnight Season 1 Tier Set Bonuses for Enhancement Shaman
Midnight Season 1 introduces the Mantle of the Primal Core, available from various endgame activities. Due to being a set in the first season following some significant changes, the benefits provided are relatively simple, providing small buffs to core strikes in  Stormstrike,  Lava Lash and  Crash Lightning between the 2-piece and 4-piece bonuses when equipped.
MANTLE OF THE PRIMAL CORE
2-Set Bonus -  Stormstrike and  Lava Lash deal 15% increased damage.
4-Set Bonus - The  Crash Lightning weapon enhancement effect increases your Mastery by 2% per stack.
 SEASON 1 TIER SET APPEARANCES
Best Tier Set Pieces for Enhancement Shaman
Our tier set bonus, Mantle of the Primal Core, is comprised of the following items from Manaforge Omega:
 Locus of the Primal Core (Helm) -  Lightblinded Vanguard
 Tempests of the Primal Core (Shoulders) - Fallen King Salhadaar
 Embrace of the Primal Core (Chest) - Chimaerus
 Earthgrips of the Primal Core (Gloves) - Vorasius
 Leggings of the Primal Core (Legs) - Vaelgor & Ezzorak
Additionally, Midnight Falls drops  Chiming Void Curio which can be exchanged at Kirana in Isle of Quel'Danas for any tier token appropriate to the difficulty it dropped in. Other item slots with the set appearances are available by using the Matrix Catalyst, but only these 5 item slots contribute to the set bonus.

To unlock each set bonus, you will need to equip 2 and then 4 pieces of the tier set. As the bonus is reasonably powerful and granted for free on top of the stats each piece grants, we always recommend using 4 pieces, ideally in these slots:

Tier Set Bonus Rotation Changes for Enhancement Shaman
While the bonus is a solid increase for both  Totemic and  Stormbringer, there's no significant rotational differences when using them. Due to it buffing both  Stormstrike and  Lava Lash, it also has a relatively similar impact for both trees, so doesn't influence build selection either. The benefits are largely passive, simply increasing the damage of abilities and providing Mastery from doing things we already do rotationally.

 HOW TO ACQUIRE YOUR ENHANCEMENT SHAMAN TIER SET BONUS IN MIDNIGHT SEASON 1
Tier sets can be acquired in three distinct ways:
Raiding: Dropped by specific bosses in Midnight Season 1 Raids.
Great Vault: Obtained by all activities that give Great Vault rewards, including raiding, Mythic+ dungeons, and open world content.
Matrix Catalyst: Creating tier armor from non-set pieces of the same item level using the Matrix Catalyst crafting system.
In Midnight Season 1, the Matrix Catalyst is unlocked for everyone from the start of the season and generates one charge every two weeks.
