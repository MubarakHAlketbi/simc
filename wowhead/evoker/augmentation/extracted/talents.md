#### Scalecommander
The recommended raid build is the "Molten Embers" build for  Scalecommander focused on damage output, as well as core class utility like  Time Spiral and  Zephyr. Note when importing this build that it does not include the Evoker interrupt,  Quell, assuming others can cover any required interrupts. If you do need an interrupt, swap out a utility node like  Chrono Ward or  Regenerative Chitin.
