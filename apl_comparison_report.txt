APL COMPARISON REPORT: C++ Generators vs .simc Override Files
=============================================================

SPEC 1: WARLOCK AFFLICTION (C++ -7.7%)
--------------------------------------
FINDING: APLs are virtually IDENTICAL. Only 1 trivial difference:
  - C++ has an EXTRA action: "dark_pact,if=talent.dark_pact.enabled&health.pct<50" in ogcd list
  - This is a defensive, not a DPS action - it would NOT cause 7.7% DPS loss
  
CONCLUSION: The 7.7% gap is NOT from APL differences. It must come from:
  - Different consumables (.simc uses harandar_celebration food, C++ defaults blooming_feast)
  - Different gear/talents in the profile
  - Or the .simc file overrides non-APL settings that affect DPS


SPEC 2: WARRIOR FURY (C++ -6.7%)
---------------------------------
FINDING: APLs are 100% IDENTICAL. Zero differences between C++ and .simc.

CONCLUSION: The 6.7% gap is NOT from APL differences. The gap must come from:
  - Profile differences (gear, talents, consumables)
  - The .simc file includes the full gear set + action overrides as a package


SPEC 3: SHAMAN ENHANCEMENT (C++ -5.0%)
---------------------------------------
FINDING: 3 differences found:

1. DEFAULT list: C++ has an extra "wind_shear" (interrupt) action.
   - This is a non-DPS action (interrupt), very minor impact.

2. SINGLE_SB list (Stormbringer ST):
   - Line 17: .simc has "lava_lash,if=buff.hot_hand.up" (conditional)
              C++ has "lava_lash" (unconditional)
   - The C++ version casts lava_lash unconditionally at this priority slot,
     while .simc only casts it with Hot Hand proc. This means C++ wastes GCDs
     on lower-value lava_lash instead of falling through to stormstrike.
   - Line 25: .simc has "frost_shock" as last-resort filler
              C++ is missing this filler entirely.

3. SINGLE_TOTEMIC list (Totemic ST):
   - Line 23: .simc has "frost_shock" as last-resort filler
              C++ is missing this filler entirely.

CONCLUSION: The main DPS-impacting difference is the unconditional lava_lash
in single_sb. The C++ generator casts lava_lash without checking for Hot Hand
proc at priority position 17, which can waste GCDs vs higher-value abilities.
Missing frost_shock fillers are very minor (rarely reached).


SPEC 4: MONK BREWMASTER (C++ -4.4%)
------------------------------------
FINDING: 2 key differences found:

1. C++ has "touch_of_death" as action #2 (right after auto_attack).
   .simc does NOT have touch_of_death at all.
   - This shifts all subsequent actions down by 1 position but they are
     otherwise identical in content.

2. C++ has "spinning_crane_kick,if=active_enemies>=3" as an AoE filler
   inserted between blackout_kick and tiger_palm.
   .simc does NOT have this action.

3. C++ has blackout_kick BEFORE rushing_jade_wind and keg_smash (unconditional).
   .simc has rushing_jade_wind BEFORE keg_smash BEFORE blackout_kick.
   The ordering difference in these low-priority fillers:
     .simc order: breath_of_fire > empty_the_cellar > rushing_jade_wind > keg_smash > blackout_kick
     C++ order:   breath_of_fire > empty_the_cellar > blackout_kick > rushing_jade_wind > keg_smash
   
   The .simc prioritizes rushing_jade_wind and the unconditional keg_smash 
   ABOVE blackout_kick, while C++ puts blackout_kick first. This reordering 
   likely accounts for the DPS difference.

CONCLUSION: The C++ generator has 3 differences from .simc:
  - Extra touch_of_death (probably minor for tank sim)  
  - Different ordering of rushing_jade_wind/keg_smash/blackout_kick fillers
  - Extra spinning_crane_kick AoE filler (ST irrelevant)
  The filler priority reordering (RJW > keg_smash > BoK vs BoK > RJW > keg_smash)
  is likely the primary cause of the 4.4% gap.


OVERALL SUMMARY
===============
- Warlock Affliction: APLs nearly identical. Gap is NOT from APL.
- Warrior Fury: APLs 100% identical. Gap is NOT from APL.  
- Shaman Enhancement: Small difference in lava_lash condition (hot_hand check).
- Monk Brewmaster: Filler priority reordering (RJW/keg_smash vs blackout_kick).

For Warlock and Warrior, the DPS gap must come from non-APL differences:
gear sets, talent strings, consumable choices, or other profile settings
in the .simc files that differ from what the C++ defaults produce.
